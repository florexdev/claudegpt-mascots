# Pip v3 - ChatGPT ve Claude maskotu

ChatGPT'de chibi robot Pip, claude.ai'da pixel karakter çıkar (popup'tan değiştirilebilir).

Kurulum (Chrome / Edge / Brave):
1. Zip'i bir klasöre çıkar.
2. chrome://extensions adresini aç, "Geliştirici modu"nu aç.
3. "Paketlenmemiş öğe yükle" ile klasörü seç.
4. chatgpt.com veya claude.ai sayfasını yenile.

Ayarlar: araç çubuğundaki Pip simgesi (karakter, boyut, dil, ses, konum sıfırlama).
Alt+M: gizle / göster. Tek tıkla dürt, çift tıkla selam ver, sürükleyerek taşı.

Arayüz değişirse content.js başındaki SELS seçicilerini (stop, editor, assistant) güncelle.
